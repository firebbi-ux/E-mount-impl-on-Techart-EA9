Custom Exit Pupil (0.5 mm Step) & Cross-Platform Edition v2.4.0-XPD0.5 (2026-11-27)

This release is a client-side enhancement built upon Ziqian Wei's open-source Community EA9 Firmware v2.4.0 (the embedded firmware binary itself remains the unmodified official v2.4.0). Key changes:

1. Unrestricted Exit Pupil Distance & 0.5 mm Step Precision (Windows & macOS)
- Removed the original 25-70 mm (5 mm step) drop-down restriction; exit pupil distance can now be freely set from 1.0 to 1000.0 mm.
- Changed adjustment increment to 0.5 mm with both spin buttons and direct keyboard decimal input (e.g., 76.5 mm), enabling accurate PDAF calibration for rangefinder wides, fast vintage SLR lenses, and telephotos.
- Updated the Windows optical builder to use floating-point exit pupil calculations matching the Python reference.

2. New Native macOS Updater (.app / .dmg for Apple Silicon & Intel)
- Built a native macOS GUI updater on top of the repository's optical/config generators and bootloader protocol using PySide6 and hidapi (native IOKit HID, driverless).
- Full feature parity with the Windows updater: single/multi-lens (8 aperture slots) configuration, hardware version selection, 0.5 mm free exit pupil input, English/Chinese UI switching, embedded release notes, and all 3 help dialogs including the hardware comparison image.

3. Revised Exit Pupil Help Documentation (Windows & macOS)
- Corrected inaccuracies in the original help text regarding exit pupil definitions.
- Clarified that exit pupil distance rarely equals focal length and auto-preselected values are for reference only, adding optical design rules (rangefinder vs. retrofocus SLR vs. telephoto) and AF-C edge calibration tips.

macOS First-Run Instructions (Important):
- Because this build is not notarized with a paid Apple Developer certificate, macOS Gatekeeper may block the first launch with an "unidentified developer" or "is damaged" warning. Follow these steps once to clear the quarantine flag:
  1) Unzip the downloaded archive, open the .dmg image, and drag EA9Updater.app into your Applications folder.
  2) Open the built-in Terminal app (via Spotlight search).
  3) Paste the following command and press Return:
     xattr -cr /Applications/EA9Updater.app
  4) You can now open EA9Updater.app normally (alternatively, check System Settings -> Privacy & Security -> Open Anyway). Remember to remove the EA9 adapter from the camera before connecting it to your Mac via USB.

Usage Note:
- Even with 0.5 mm exit pupil calibration, AF-S misfocus—especially at wide apertures and when focusing near frame edges on certain lenses—remains a known limitation of the v2.4.0 firmware (due to Sony body AF-S sweep protocol compatibility and the LM-EA9's mechanical micro-stepping limitations, which cannot be fully resolved by exit pupil refinement alone). Please keep your camera in AF-C mode for daily shooting (back-button AF-ON recommended).

Firmware 2.4 (22 November 2026)

- Fixed aperture stuck at minimum in multi-lens mode.

Known limitations:
- Only AF-C works; AF-S still misses focus.

==== Previous versions ====

Firmware 2.3 (20 November 2026)
- Different focal lengths can now be selected with the aperture.
- Custom exit pupil distance, for better phase-detect AF at different focal lengths.
- A stricter return to infinity on version 1 adapters.

Firmware 2.2 (12 November 2026)

- 4th-generation bodies and newer are now supported!
- Focus tracking now works during AF-C burst shooting.
- Improved motor homing at start-up.

Firmware 2.1 (10 November 2026)

- Focus now returns to infinity when you switch to MF.
- Proper support for the camera's sleep mode.
- More reliable start-up and shutdown, and faster shutdown.
- More robust communication with the camera.

Firmware 2.0 (4 November 2026)

- The adapter now identifies itself as a native E-mount lens.
- Autofocus now works in video mode.
- Improved AF-C range and tracking.
